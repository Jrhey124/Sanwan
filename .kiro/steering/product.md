# Sanwan — Product Overview

Sanwan is a Discord ChatOps bot designed for small self-hosted teams (e.g. running on a Raspberry Pi or home server). It lets team members manage operations directly from Discord without needing to SSH into a machine or switch to a separate tool.

## Core Features

- **Task management** — create, assign, and track tasks with deadlines and status updates
- **Notes** — create and maintain shared notes; push/pop lines, search by keyword, export as files
- **Scheduling** — define named cron jobs that run commands on a schedule with Discord notifications
- **Log access** — read bot logs and registered external log sources from Discord
- **System resources** — inspect disk usage, CPU/memory, and network info (OS-aware)
- **Deploy control** — start, stop, restart, and check the status of registered services
- **GitHub integration** — receive push, PR, workflow, and release notifications via webhook or polling
- **Daemon** — a separate background process that runs scheduled tasks and sends task deadline reminders

## Target Users

Small technical teams managing self-hosted infrastructure who want a single Discord interface for operational tasks.

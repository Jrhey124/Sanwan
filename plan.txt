/task
    add <task> <assignee> <deadline>
        → Create a new task with assignment + deadline (coding or non‑coding).
    update <task | tid> <field> <value>
        → Update status, deadline, assignee, or description.
        Example: /task update 12 status in-progress
                 /task update "Hardware assembly" deadline 2026-08-30
    describe <task | tid> <description>
        → Add or refine the task’s detailed description.
        Example: /task describe "Write documentation" "Draft API reference section"
    list
        → Show all tasks with assignee, deadline, status.
    remove <task | tid>
        → Delete a task.
    notify <task | tid>
        → Manually trigger a Discord reminder.
    due <days>
        → List tasks due within X days.
    link <task | tid> <issue#>
        → (Optional) connect a task to a GitHub issue if it’s code‑related.    
    sync
        → (Optional) sync tasks with GitHub issues.
